## Strengths and weaknesses (from the listings and 1–2★ reviews)
- **Bitwarden / Proton Pass.** Strengths: autofill, passkeys, cross-device sync, trusted brands.
  Weakness: an account and the cloud are required, which is the gap an offline vault fills.
- **KeePassDX / Keepass2Android.** Strengths: open source, a standard file format, autofill, TOTP.
  Weaknesses: a technical first run and too many tutorial pop-ups (KeePassDX), unreliable auto-lock, and an
  "Offline" build that users reported still making network connections.
- **SafeInCloud.** Strengths: password health (weak, reused, compromised), a Wear OS app, and backup to your own cloud.
  Weakness: complaints about lifetime purchases being charged again.
- **Enpass.** Weaknesses: a forced redesign that opens to a dashboard, a hidden item cap, and the highest 1★ share in the set (20%).
- **My Passwords / Password Safe.** These are the closest offline peers and the best rated (4.6–4.75).
  Strengths: TOTP, autofill, Wear OS, a generator widget, and import from many managers.
  Weaknesses: backup/restore data loss after updates, and a paywall on autofill.
- **Small "offline" apps** (One Key, desmundyeng). Weaknesses: network access added after launch, and item caps.

## Title takeaway
Almost every top title contains "Password Manager" or a synonym (Safe, Saver, Vault), with the brand second.
"Passkey" now appears in the short descriptions of Bitwarden, Proton, SafeInCloud, Enpass, My Passwords and
Password Safe, and in KeePassDX's title.
